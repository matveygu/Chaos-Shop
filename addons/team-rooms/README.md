# Chaos Shop · Комната на двоих

Два игрока входят в одну комнату на время матча. Ведущий выбирает категории и тир. Оба видят те же три карты и один общий переброс. Каждый выбирает предмет для своего героя и оплачивает его своими душами. После покупки у обоих игроков ведущий может начать следующий ролл. Если подходящих карт у игрока нет, он может пропустить выбор.

## Подключение в Deadlock

1. Оба игрока включают `chaos_shop_team_rooms.vpk` отдельным модом в менеджере. Для переключения между версиями включайте только одну сборку Chaos Shop.
2. Ведущий открывает **? → Комната на двоих**, вводит HTTPS-адрес сервиса, нажимает **Подключиться → Создать комнату → Копировать** и отправляет приглашение другу.
3. Друг вставляет приглашение в поле адреса в том же разделе и нажимает **Подключиться**. Если у него уже открыт тот же сервис, достаточно ввести короткий код из приглашения и нажать **Войти**.
4. При **2/2** ведущий нажимает тир. До первого выбора он может один раз перебросить всю тройку. Для каждого игрока уже купленные или недоступные предметы помечаются отдельно.
5. Клик по карте закрепляет личный выбор после подтверждения сервиса. Обычный магазин покупает предмет в радиусе лавки при достаточном количестве душ. Если один игрок закрыл магазин, состояние подтянется при возвращении во вкладку. Кнопка **Выйти** внутри комнаты закрывает её для обоих.

Комната рассчитана на двоих и действует до четырёх часов. Ролл и переброс передаются через сервис. Он получает код комнаты, случайный идентификатор участника и данные драфта. Steam-аккаунт и доступ к игровому серверу ему не нужны.

## Сервис

Требуется Node.js 22 или новее. Зависимостей для запуска нет. Из каталога этой сборки:

```powershell
node service/server.mjs
```

Для локальной проверки веб-страница доступна на `http://127.0.0.1:8787/`. Два разных профиля браузера представляют двух игроков. Комнаты хранятся в памяти одного процесса. После перезапуска создайте новую комнату.

Для игры с другом разместите сервис на машине, доступной обоим, по HTTPS с доверенным сертификатом. Через обратный прокси направьте корень отдельного домена на локальный порт 8787 и сохраните исходный заголовок Host. Для прямого HTTPS процесс принимает переменные `ROOM_TLS_CERT` и `ROOM_TLS_KEY` (пути к сертификату и ключу в PEM), `ROOM_HOST` (по умолчанию 127.0.0.1) и `ROOM_PORT` (по умолчанию 8787). Один и тот же VPK работает с разными доменами. У этой сборки пока нет публичного адреса по умолчанию.

## Проверка и откат

```powershell
node --test tests/room.test.mjs
node tests/shop.test.cjs
```

Для браузерного теста `node tests/browser.mjs` дополнительно нужен Playwright с Chromium. Переменная `ROOM_PLAYWRIGHT` может указывать на установленный пакет, `ROOM_BROWSER` — на исполняемый файл Chromium или Edge. Тест запускает отдельный локальный сервис и два изолированных браузерных контекста.

Для отката выключите эту сборку, включите предыдущий Street Draft или первоначальный Chaos Shop и перезапустите Deadlock. Предыдущий Street Draft находится по относительному пути `../street-draft/chaos_shop_street_draft.vpk`, оригинальная версия — `../street-draft/rollback/random_shop.vpk`.

Схема приватной комнаты основана на открытом описании [Deadlock Ability Draft](https://github.com/Binger4/Deadlock-Ability-Draft). Сервис и код синхронизации написаны для Chaos Shop.
