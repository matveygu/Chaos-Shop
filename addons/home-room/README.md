# Chaos Room для Windows x64

Комната Chaos Shop живёт на ПК ведущего во время матча. Приложение получает временный HTTPS-адрес у Cloudflare и выдаёт два приглашения. Аккаунт, домен, аренда сервера и настройка роутера для этого режима не требуются.

## Сыграть вдвоём

1. Оба игрока включают **chaos_shop_team_rooms.vpk** в менеджере модов и запускают Deadlock с одной активной версией Chaos Shop. Другу нужен только этот VPK. Если у вас уже стоит сборка **Team Rooms**, она совместима.
2. Ведущий распаковывает архив целиком, запускает **ChaosRoom.exe** и нажимает **Создать комнату**. Когда обе ссылки станут доступны, ведущий отправляет другу нижнюю, а верхнюю копирует себе.
3. В игре каждый открывает **Random → ? → Комната на двоих**, вставляет свою ссылку в поле адреса и нажимает **Подключиться**. Любой из вас может войти первым.
4. При **2/2** ведущий выбирает тир. Оба получают одинаковые карты. Один общий переброс доступен до первого выбора. Каждый выбирает и покупает свой предмет.

Оставь окно ведущего открытым до конца матча. Чтобы закончить, нажми **Закрыть комнату** или закрой окно. Кнопка **Выйти** в комнате также завершает сессию для двоих. Через четыре часа комната закроется автоматически. Для следующей сессии создай новые приглашения.

Если ссылки так и не появились, ведущий может повторить подключение или передать роль ведущего другу. Quick Tunnels предназначены для временных тестов и зависят от доступности Cloudflare у обоих игроков. При полностью автономной игре одинаковую последовательность карт можно получить по общему коду в отдельной сборке Street Draft. Там игроки самостоятельно выбирают одинаковые тир, категории и переброс.

## Как устроено подключение

Приложение открывает локальный сервис на случайном порту адреса 127.0.0.1. Поставляемый cloudflared соединяет этот сервис с временным адресом. Ссылки появляются после того, как приложение через HTTPS получит случайный маркер именно своей сессии. Веб-сервис отдаёт только страницу комнаты, её ресурсы, маркер и API драфта. Первое использование личной ссылки закрепляет место за браузерным клиентом. Ведущий хранит свою ссылку у себя. Ссылку гостя можно передать личным сообщением.

В проекте остаются исходники окна в каталоге src, сервис в service и тесты в tests. Для сборки окна из папки пакета:

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /codepage:65001 /optimize+ /platform:x64 /target:winexe /r:System.Windows.Forms.dll /r:System.Drawing.dll /r:System.Net.Http.dll /out:ChaosRoom.exe src\ChildJob.cs src\RoomWindow.cs
```

Проверка сервиса запускается командой `.\runtime\node.exe --test tests/home.test.mjs tests/room.test.mjs`. Для `tests/browser.mjs` укажи путь к пакету Playwright в переменной ROOM_PLAYWRIGHT и к Edge или Chromium в ROOM_BROWSER. По умолчанию тест работает на локальном адресе.

Переносной комплект содержит официальные Windows x64 версии Node.js 24.22.3 и cloudflared 2026.11.1. Их лицензии лежат в runtime. [Node.js](https://nodejs.org/dist/v24.22.3/) · [Релиз cloudflared](https://github.com/cloudflare/cloudflared/releases/tag/2026.11.1) · [Документация Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

## Что проверено

В установленной сборке Deadlock 6864 из pak01_dir.vpk извлечены и просмотрены по поиску 445 файлов разметки. В citadel_ui_party_code.xml код приглашает в игровую группу. В citadel_ui_context_menu_game_chat.xml есть режим чата группы, а chat.xml отправляет введённый текст через CitadelChatInputSubmitted. В этой разметке и в доступных скриптах магазина не найден приватный канал для произвольных данных мода. Встроенная веб-панель CitadelHTMLPanel используется самой игрой в popup_news_post.xml.

У Ability Draft состояние комнаты и выборы хранит веб-сервис. Steam предоставляет нативный интерфейс для отправки сообщений, но его привязку к JavaScript магазина в проверенных ресурсах найти не удалось. WebRTC потребовал бы обмена данными для установления соединения, а в некоторых сетях также потребовался бы ретранслятор TURN. [Ability Draft](https://github.com/Binger4/Deadlock-Ability-Draft) · [Steamworks](https://partner.steamgames.com/doc/api/ISteamNetworkingMessages) · [WebRTC](https://webrtc.org/getting-started/peer-connections)

22 ноября 2026 года приложение на Windows создало временный публичный адрес. В двух отдельных профилях Edge проверены вход гостя первым, общий ролл и переброс, разные выборы, перезагрузка страницы гостя, подтверждения покупок со стороны тестовых клиентов и второй раунд. После выхода адрес отключился, процессы сервиса и туннеля завершились. Локальный тест также воспроизводит обрыв первого запроса на вход и проверяет автоматическое восстановление. Испытание с двумя запущенными копиями Deadlock остаётся отдельной проверкой. Исходники совместимого VPK находятся в соседней папке team-rooms/panorama.

Для отката закрой Chaos Room, выключи Team Rooms в менеджере и включи свою предыдущую версию Chaos Shop.
